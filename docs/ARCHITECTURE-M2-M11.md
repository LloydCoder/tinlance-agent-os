# M2-M11 Architecture\n\nThe daemon, durable OS state, workflows, memory, applications, shell, extensions, enterprise seams and distribution state all remain above the Agent Platform authority boundary.\n\nState owned by OS: workspace/session/task/workflow/application lifecycle and non-restricted local context.\n\nState owned by Platform: identity, tenancy authorization, policy, approvals, budgets, governed execution and authoritative evidence.\n\nSecurity controls include same-user local daemon peers, bounded requests, cycle-checked workflows, scoped/classified memory, declarative capabilities, secure remote endpoints and content-addressed update verification.\n\nObservability should use OpenTelemetry events for lifecycle/state changes and spans for operations with duration; sensitive prompt, memory and credential content is excluded by default.\n
