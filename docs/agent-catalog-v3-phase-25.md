# Agent Catalog v3 — Phase 25: Domain Expansion

Phase 25 expands the semantic domain layer without using industry, geography, customer identity, model/provider, tool, protocol, or permission variants as artificial taxonomy entries.

## Domain families

The controlled seed spans eight families:

1. engineering
2. security
3. data
4. business
5. regulated
6. science
7. human-services
8. operations

The phase seed contains more than 48 canonical domain IDs. Each domain has explicit inclusion and exclusion criteria and a stable semantic key.

## Non-inflation rule

A domain must represent a materially distinct area of work. A new canonical domain is not justified merely by:

- country or region;
- customer/workspace;
- model or provider;
- deployment environment;
- tool or protocol;
- cost or latency tier;
- authorization level.

Potentially overlapping domains must remain reviewable rather than being multiplied by naming conventions.

## Authority boundary

Domain definitions are descriptive metadata. They do not grant capability, authorization, approval, tool access, secrets, sandbox rights, execution rights, or registry ownership.

## Gate

Phase 25 is complete only after full CI, dependency/security checks, merged-main CI, and a forensic post-merge audit.
