# M28 Event, Signal & Reactive Runtime

## Delivered

- durable event envelopes;
- workspace-scoped subscriptions;
- deterministic deduplication;
- bounded delivery attempts;
- dead-letter queue semantics;
- explicit replay;
- correlation IDs;
- acceptance tests and package exports.

## Boundary

Events are OS lifecycle/data signals. They are never authorization, capability grants, approvals, Platform runs, or authoritative evidence.
