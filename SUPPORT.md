# Support

Use the support path that matches your question.

| Need | Where to go |
| --- | --- |
| Bug in the repository | Open a GitHub issue using the bug report form |
| Feature proposal | Open a GitHub issue using the feature request form |
| Usage or development question | Open a GitHub issue with enough reproducible context |
| Architecture question | Review [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and then open an issue if clarification is still needed |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); do not use a public issue |
| Contribution process | Read [CONTRIBUTING.md](CONTRIBUTING.md) |

## When requesting help

Include the project version or commit, Python version, operating system, exact command, relevant output, and a minimal reproduction when possible.

Remove credentials, tokens, customer information, private keys, and other sensitive data before posting.
